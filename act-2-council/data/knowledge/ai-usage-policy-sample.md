# Sample AI Usage Policy

> **Fictional demo policy.** This policy does not describe a real organisation.

## Allowed use

Approved coding agents can assist with public, internal, and synthetic data when the selected model
and hosting path are approved for that classification.

## Required controls

* Review generated changes before merge.
* Run the repository checks.
* Do not enter credentials, personal data, customer data, or restricted source code into an
  unapproved service.
* Record the model, provider, and material tool calls for important decisions.
* Use an approved model register. A protocol such as MCP is not itself a hosted service.

## Exceptions

The engineering owner and security owner must approve an exception before use. An incident or
deadline does not create automatic approval.
