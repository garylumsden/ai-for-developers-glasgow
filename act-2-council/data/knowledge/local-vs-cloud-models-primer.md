# Local and Cloud Model Primer

Local and cloud models have different operational strengths.

## Local models

* Can continue when an external network is unavailable.
* Can keep prompts and source files on team-controlled hardware.
* Need suitable hardware, model files, runtime updates, and local support.
* Have fixed device context, memory, and throughput limits.

## Cloud models

* Can provide larger models and managed capacity.
* Can receive model and safety updates without workstation maintenance.
* Need network access and an approved data-handling path.
* Can create variable token and service costs.

## Hybrid routing

A hybrid policy routes work by sensitivity, capability, latency, and cost. Measure the complete task,
not only model generation speed. Include tool execution, retries, validation, and operator effort.
